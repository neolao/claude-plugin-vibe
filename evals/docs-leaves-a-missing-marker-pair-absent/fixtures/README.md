A tiny CLI to manage widgets from the command line.

## Installation

<!-- vibe:begin:install -->
Requires Node.js. From a checkout of this repository:

```sh
npm install -g .
```

Check it with `widgetcli list`. Remove it with `npm uninstall -g widgetcli`.
<!-- vibe:end:install -->

## Usage

<!-- vibe:begin:usage -->
```sh
widgetcli add "My widget"
widgetcli list
widgetcli list --json
```
