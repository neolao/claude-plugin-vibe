## Project overview

widgetcli is a tiny CLI to manage widgets from the command line: `add` stores a widget, `list` prints them, `list --json` prints them as JSON. The team behind it is French-speaking and the widget names it stores are French product labels.

**Stack:** Node.js / node:test
**Type:** CLI
