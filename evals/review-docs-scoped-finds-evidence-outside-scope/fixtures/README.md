# Ledger

Ledger imports bank statements, reconciles them against invoices and exports the result for the accountant.

## Documentation

The reference pages under `docs/reference/` are the authoritative source for every limit, format and command; the guides restate what a task needs and point to the reference for the rest.

- [docs/guides/import.md](docs/guides/import.md) — importing a bank statement
- [docs/reference/formats.md](docs/reference/formats.md) — the file formats Ledger reads and writes
- [docs/reference/limits.md](docs/reference/limits.md) — every limit the service enforces
- [docs/reference/cli.md](docs/reference/cli.md) — the `ledger` command and its options
