# Caching

`src/cache/lru.js` keeps the last widget listing in memory.

- `list` reads from the cache first and falls back to `src/storage/store.js` on a miss.
- `add` clears the cache after writing, so the next `list` reads the file again.
- The cache holds a single entry and has no expiry.
