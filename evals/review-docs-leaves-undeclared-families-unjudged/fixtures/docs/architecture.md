# Architecture

A statement goes through three steps: a reader turns the file into transactions, `src/reconcile.py` matches each with an open invoice, and the export writes the matches of a period for the accountant.

```mermaid
flowchart LR
  Reader --> Reconcile --> Export
```

The readers are the only place a bank-specific quirk is handled; reconciliation and export see normalized records only.
