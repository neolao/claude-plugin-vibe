# Architecture

Two modules make up the library.

- `greet.js` — the public entry point: `greet(name)` builds the greeting.
- `format.js` — string helpers used by `greet.js` (`exclaim`).

Data flow: the caller's name goes into `greet()`, which hands the sentence to `exclaim()` and returns the result.
