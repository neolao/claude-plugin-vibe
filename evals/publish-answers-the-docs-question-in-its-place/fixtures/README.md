# tiny-pub-lib

A tiny Node.js library that greets people by name.

## About this project

Tiny-pub-lib started as a weekend exercise in publishing a package by hand; this paragraph is maintained entirely by hand and must never be rewritten by any tooling, no matter what else changes in this file.

## Getting started

Copy `greet.js` and `format.js` next to your code, then `require('./greet')` and call `greet('Ada')`.
