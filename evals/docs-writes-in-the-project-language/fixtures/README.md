# widgetcli

Un petit outil en ligne de commande pour gérer des widgets.

## À propos du projet

Widgetcli est né d'un week-end de bricolage pour apprendre à empaqueter de petits outils en ligne de commande ; ce paragraphe est tenu à la main et aucun outil ne doit le réécrire, quoi qu'il arrive au reste du fichier.
