# Architecture

widgetcli has two modules.

- `src/commands/` parses the arguments and runs one command: `index.js` dispatches to `add.js` or `list.js`.
- `src/storage/` owns the widget file: `store.js` reads and writes `widgets.json`.

Commands never touch the file directly. They call `readWidgets()` and `writeWidgets()` from the storage module.

The file lives in `$WIDGETCLI_HOME/widgets.json` when the variable is set, otherwise at the project root.
